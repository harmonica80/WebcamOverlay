# 節慶與活動裝飾（v0.2.41）

在完整設定中展開「節慶與活動裝飾」，選擇攝影機或「同步調整」，再點選主題即可開啟。每台同時顯示一個裝飾圖層，可選「全畫面場景」或「自由貼圖」。

## 10 款內建主題

新年燈籠、春日櫻花、端午粽香、中秋月兔、萬聖南瓜、聖誕雪花、生日氣球、畢業星光、教師謝意、運動加油。

每款均提供場景與貼圖兩種構圖；「播放動畫」可切換動態與靜態圖形。場景不再使用四角等大的圖案，改成大小錯落、不對稱的配置，框線預設關閉。內建素材包含透明插畫與向量圖形，動畫由程式播放，所有素材隨程式提供，不需網路。

| 主題 | 場景動畫 |
| --- | --- |
| 新年燈籠 | 插畫燈籠輕擺、獅頭、紅包飄落及煙花綻放 |
| 春日櫻花 | 花枝與大小不同的花瓣，從上方飄落並旋轉 |
| 端午粽香 | 大小粽子與飄落綠葉 |
| 中秋月兔 | 插畫明月、移動雲層、桂花飄落與月兔輕躍 |
| 萬聖南瓜 | 大小南瓜與橫向飛過的蝙蝠 |
| 聖誕雪花 | 大小聖誕樹與持續飄雪 |
| 生日氣球 | 不同大小與顏色的氣球向上飄 |
| 畢業星光 | 插畫學士帽拋起、紙飛機掠過、畢業證書與彩紙飄落 |
| 教師謝意 | 書本與緩緩上升的愛心 |
| 運動加油 | 獎盃與旋轉落下的彩紙 |

- 「場景圖案大小」可調 50–180%，同時保留大、小圖案之間的差異。
- 想要框線時勾選「加上細框線」。此選項只影響內建場景。
- 「自由貼圖」大小可調 10–100%，適用內建與自訂圖檔。百分比是圖片畫布占視窗的比例，包含透明邊距。
- 取消「播放動畫」後會顯示完整的靜態構圖；放大圖案可能超出視窗邊緣。
- 場景大小滑桿不會重啟動畫；兩台可分別調整。

## 自訂 PNG／APNG

點選「匯入 PNG／APNG」，選好素材後調整模式、不透明度；貼圖另有九宮格位置與大小。攝影機的鏡像、亮度、色相及去背不影響裝飾。

| 用途 | 建議畫布 | 注意事項 |
| --- | --- | --- |
| 矩形或圓角外框 | 1280 × 720 px | 16:9，中央約 70% 留透明 |
| 圓形外框 | 800 × 800 px | 1:1，中央與四角透明，自訂外框不會自動改形 |
| 角落貼圖 | 512 × 512 px | 四周保留少量透明邊距 |
| APNG 動畫 | 512 × 512 或 640 × 360 px | 建議 10–15 fps、2–4 秒，匯出時設定無限循環 |

限制：檔案不超過 20 MB，寬高各不超過 2048 px，動畫最多 120 格，畫布寬 × 高 × 格數不超過 64,000,000 像素。

1. 建立透明背景畫布，加入圖案與正向文字。白底不會自動透明。
2. 靜態匯出 PNG；動畫須使用支援 APNG 的工具。改副檔名不能轉換 GIF、影片或靜態圖片。
3. 匯入後使用預覽確認。圖片會依比例完整顯示，不會拉伸；普通 PNG 不因勾選「播放動畫」而自動產生動畫。APNG 關閉播放動畫時顯示預設靜態畫面。
4. 確認裝飾沒有遮住臉部或重要手勢。素材被邊界裁切時，將圖案往畫布內側移。

程式內的「自製圖檔規格與教學」按鈕可直接開啟相同規格說明。

## 保存、搬移與使用範圍

匯入會在設定資料夾的 `decorations` 子資料夾保存副本，通常是 EXE 旁的 `Data/decorations`。不記錄設定時仍保留匯入副本，但下次不會自動套用；只有勾選「記錄設定，下次啟動時自動套用」才還原主題與設定。重設設定關閉裝飾與記錄，不刪除素材副本。搬移工具時請一起保留 `Data`。

同步調整只改本次操作的欄位。例如同步不透明度，不會改掉兩台原有的不同主題。裝飾目前跟隨攝影機 1／2 的設定槽位；原有交換來源操作仍沿用原本的設定槽位規則。

裝飾呈現在桌面的攝影機浮動視窗中，並非虛擬攝影機輸出。大型動畫與雙路去背的長時間效能仍需在實際使用電腦驗證。
