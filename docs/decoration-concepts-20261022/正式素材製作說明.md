# 正式素材製作說明

使用者確認三張概念圖後，使用內建 imagegen 工具、以原始概念圖為參考，生成三張透明 PNG 素材圖集。各含六個元素，由程式分層顯示與播放動畫，原始檔保持不變。

正式素材位於 `src/assets/decorations/`：`newyear-v041.png`、`moon-v041.png`、`graduation-v041.png`。底色、人像與提案文字不包含在素材中。

## 生成提示詞

### newyear

Create a production PNG sprite atlas from the attached APPROVED design reference. Use its refined dimensional painterly illustration style, colors, details and object designs. OUTPUT: exactly 1536x1024 landscape, a STRICT invisible 3-column by 2-row grid of six equal 512x512 square cells. One isolated object per cell, centered in that cell, full object fits inside its cell with 40 pixels transparent margin on every side; no object crosses a cell boundary. Absolutely genuinely TRANSPARENT alpha background, not white, not checkerboard drawing. No labels, no text, no titles, no grid lines, no person, no mockup background, no frame, no cast shadow on background. The output is assets for compositing over live camera video, NOT the original mockup. Fine semitransparent edges and subtle painted object shading are welcome. Objects must closely match reference artwork. Each cell object roughly fills 80% of cell while keeping its natural aspect ratio. Grid order left to right, top row then bottom row: 1. One ornate round RED and GOLD hanging lantern, complete golden hanging loop and long red flowing tassel, floral pattern. 2. One slender ivory-gold oblong hanging lantern with red flower decoration and red tassels. 3. One elegant diagonal red plum blossom branch with a flowing red-gold silk ribbon, compact isolated branch, no lanterns. 4. One adorable red/gold/ivory traditional lion-dance HEAD looking at viewer, complete head with rich fluffy eyebrows, round expressive eyes, no body. 5. One tilted vivid red envelope with a simple round golden floral seal (no writing). 6. One gold and red radial firework burst of delicate glowing strokes, isolated on transparent alpha, no big background disk.
